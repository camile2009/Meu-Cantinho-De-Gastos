# 🌸 Meu Cantinho de Gastos

Um cantinho para controlar o dinheiro do mês de um jeito fofo e simples.

👉 **Testar o app:** https://camile2009.github.io/Meu-Cantinho-De-Gastos/

## O que ele faz

- 💰 **Entradas de dinheiro:** registre quanto entrou no mês (salário, mesada, presentes...), cada uma com descrição e data
- 🧾 **Gastos:** lance o valor, o que foi, a área e a data
- 🤔 **Foi necessário?** classifique cada gasto como necessário, podia ter esperado ou impulsivo
- 🐷 **Guardar dinheiro:** crie objetivos com meta e acompanhe o progresso
- 🎯 **Limites por categoria:** defina quanto quer gastar em cada área e veja a barra avisar quando passar
- 🍩 **Gráfico:** veja para onde foi o seu dinheiro
- 📅 **Navegação por mês:** cada mês tem as suas próprias entradas e gastos
- 🌷 **Áreas personalizadas:** escolha ou crie as categorias que combinam com você

## Como usar

1. Abra o link acima
2. Escolha as áreas em que você costuma gastar
3. Adicione as entradas de dinheiro do mês
4. Vá lançando seus gastos e acompanhe os cards **Entrou**, **Gastei**, **Guardei** e **Sobrou**

Os dados ficam salvos no próprio navegador, então só você vê o que lançou.

## Tecnologias

- HTML, CSS e JavaScript puro, em um único arquivo
- Dados salvos com localStorage
- Publicado com GitHub Pages
- Modo claro e escuro automático
